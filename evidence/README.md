# Runtime evidence

Exact-source evidence is generated outside the checkout by `scripts/verify-prototype.sh` and uploaded by the unconditional Full product gate as `resilience-loom-evidence-<source-sha>`.

The external artifact contains the schema-2 manifest, composition report, semantic review, all ten recorder suites, Playwright report/trace, desktop/mobile screenshots, correlation logs, Cargo metadata, selection report and original readiness probe archive.
