# Ubiquitous language

## Model
Incident objective means the operator-stated outcome; response cell means the separated agents; recovery contract means authorized scoped work; upstream analysis means the seven-project executed evidence; durable plan means a read-back-confirmed RVF record; audit chain means tamper-evident history.

## Invariants
Code, API schema, frontend labels, tests, and docs use these terms consistently. Legacy Mandate Mesh terms appear only in benchmark attribution and never as product entities.

## Events and verification
Semantic review searches for drift, while client and schema tests keep public language synchronized.

## Boundary rule
Types cross this boundary through explicit domain values; upstream library types and storage representations remain inside their owning adapters.
