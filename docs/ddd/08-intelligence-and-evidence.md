# Upstream intelligence composition

## Model
UpstreamAnalysis contains AgentDB evidence hits, DSPy playbook priority, Ruflo coordination identity, and Sublinear allocation metrics. RuVector analogue recall and OpenTelemetry spans remain typed Rust boundaries.

## Invariants
All selected upstream results must be present before plan persistence. A non-zero child exit, malformed JSON, timeout, dimension mismatch, or trace failure aborts the command.

## Events and verification
UpstreamsExecuted lists exact canonical projects and correlation ID. Readiness receipts and integration tests prove each success and failure path.

## Boundary rule
Types cross this boundary through explicit domain values; upstream library types and storage representations remain inside their owning adapters.
